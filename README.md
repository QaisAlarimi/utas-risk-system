# UTAS Risk Management System (AI-assisted) - prototype

Run:  pip install -r requirements.txt  &&  streamlit run app.py
(SQLite by default. For MySQL set  DATABASE_URL=mysql+pymysql://user:pass@host/dbname )

## Roles (match the UI design: Login with role, 4 screens x EN/AR)
- Visitor: reports a risk with NO login ("Report a risk without logging in"), gets a tracking code (Track page).
- User (login): Report a Risk + My Reports + recent reports panel; sees if a report was returned and why.
- Administrator: Reports table + details, AI suggestion (category/type/likelihood x severity - editable), approve & send to the
  Responsible department or return to user, stepper (Submitted > Admin Approval > Responsible Action > Final Decision),
  close report / request more action; Users page (add/delete users); Settings (AI model, training data export, re-train).
- Responsible Person (login): Assigned Reports tabs (New / In Progress / Done), Your Response (solution, status, date, evidence), History.
  Sees reports assigned to them or routed to their department.

## AI
**Install note:** requirements pin scikit-learn==1.6.1 (the team's Colab model was saved with it; newer versions cannot load it).
If you installed a newer one earlier, run `pip install -r requirements.txt` again to downgrade.
- Risk-LEVEL model (models/campus_risk_level_model.joblib, from the team's Colab notebook, Gradient Boosting): trained on
  PROVISIONAL labels generated by a likelihood x severity rule (synthetic, not expert-approved), so it mostly re-learns that rule.
  Needs the reporter's likelihood AND severity (optional fields in the report form); otherwise no level suggestion is shown.
  Shown to the admin as a provisional suggestion only; the admin's likelihood x severity decision is final.
The AI only SUGGESTS category/type (and a proposed level); a human confirms or edits. Verified decisions become labels.
- Model (models/category_model_synthetic.joblib): TF-IDF (word+char) + Logistic Regression, trained by
  `python train_model.py` on the supervisor's Campus_Risk_Dataset_1000_Synthetic_Reports.xlsx (1000 rows, 59 subtypes).
  That file is SYNTHETIC and templated: hold-out macro-F1 = 1.00 only proves the pipeline works. Do NOT quote it as real accuracy.
- The dataset has NO verified risk level (left blank by the supervisor), so the model predicts type/category only.
  The level comes from likelihood x severity decided by the human (proposed thresholds, to be confirmed).
- The model learned English only; Arabic reports and low-confidence cases fall back to keyword rules (keywords.py).
- Admin > ML Dataset > "Train model on verified data" builds a new model from REAL verified reports once
  >=100 rows and >=2 types with >=5 examples exist; it is then preferred automatically.
